Project Overview

Academic personal website for Michael Baumgartner (University of Bergen, Philosophy). Built with R Markdown (rmarkdown::render_site()) using the Bootstrap “sandstone” theme. Published to GitHub Pages.

Key Commands

All commands run in R (via Rscript or RStudio console).

# Build the full site (outputs to _site/) — docs/ is NOT copied by render_site()
# (it is in _site.yml's exclude list), so use the wrapper that also syncs docs/
# to _site/docs/ (needed for the CNA banner docs/head_cna3.png and PDFs)
source("script.R")
render_site_with_docs()

# Build the full site without docs/ sync (raw)
rmarkdown::render_site()

# Build a single page (faster iteration)
rmarkdown::render_site(input = "index.Rmd")

# Re-sync docs/ to _site/docs/ after any render (e.g. if images/PDFs are missing)
sync_docs_to_site()

# Preview a single page using the preview/ directory
source("script.R")
preview_homepage("index.Rmd")

# Preview the full site
render_preview_site()

# Publish to gh-pages (pushes to remote)
publish_site()
publish_page("index.Rmd")

Architecture

  • Source pages: .Rmd files at root — index.Rmd, vita.Rmd, publications.Rmd, talks.Rmd, research.Rmd, teach.Rmd, cna.Rmd
  • Site config: _site.yml — navbar structure, output theme, output dir (_site), file exclusions
  • Custom CSS: basic.css — Navy & Burgundy color scheme (links #8a1f2d, accents #1f3a5f, featured/de-highlight tint #f2f0ea). Tinted backgrounds are used to de-highlight past/archived content (e.g. Past Projects, former teaching posts), not current content. Alternative schemes preserved in schemes/ (open schemes/index.html to compare)
  • Bibliography: bib.bib — BibTeX file for publications/citations
  • Documents: docs/ — PDFs and images (papers, programs, course outlines, CNA banner head_cna3.png). Not copied to _site/ by render_site() (excluded in _site.yml) — run sync_docs_to_site() or use render_site_with_docs()
  • Helper scripts: script.R — utility functions for rendering, previewing, and publishing
  • Preview workflow: preview/ directory mirrors the site with symlinks, uses preview-basic.css for dev iteration
  • Published output: _site/ — rendered HTML, then synced to gh-pages branch

Important: CLAUDE.md Exclusion

rmarkdown::render_site() processes all .Rmd and .md files in the root directory. CLAUDE.md must be listed in the exclude field of _site.yml, otherwise it will be rendered as CLAUDE.html and pushed to the published site.

Publishing Workflow

publish_site() in script.R: 1. Renders the site via rmarkdown::render_site() 2. Clones/fetches the gh-pages branch into .publish-cache/ 3. Syncs _site/ content into the cache (uses rsync --delete=false — no files on gh-pages are ever deleted) 4. Syncs docs/ directory separately 5. Commits and pushes to origin/gh-pages

RStudio Project

.Rproj file sets BuildType: Website, meaning RStudio’s “Build” button runs rmarkdown::render_site().
